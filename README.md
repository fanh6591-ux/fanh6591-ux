## 我怎样做项目

1. **看清问题**：明确谁在使用、流程卡在哪里、改进后怎样判断有效。
2. **建立基线**：梳理现有数据、规则、系统和人工处理方式。
3. **做出试点**：把输入、处理、复核与输出串起来，在具体场景中验证。
4. **留下成果**：交付工作流、数据口径、验收记录与团队使用方法。
